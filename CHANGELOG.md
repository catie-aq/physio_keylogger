## [0.1.0+20250626] - 2025-06-26

### Added
- First release of the Physio Keylogger tool.
- Command-line interface (CLI) to record key events and export to CSV.
- Graphical user interface (GUI) using Tkinter.
- CLI options to filter key up / key down events.
- GUI options to select output directory, event types, and live logging.
- CSV output including timestamp, scan code, key name, and event type.
- PyInstaller build spec for standalone binaries.
